# 2027年大学生创新训练、科研训练项目预立项与在研项目检查｜官方通知导航

> 来源类型：东北林业大学本科生院公开官方通知（2026-11-11）。这是学生学习用的**原创简述**，不是校方公告原文或替代申报文件。核验日期：2026-11-12（北京时间）。适用对象、学院执行节点以原通知及学院最新安排为准。

**官方原文**：https://bksy.nefu.edu.cn/info/1021/8585.htm

## 谁应该关注

- **计划申报2027年项目**：学校全日制在读**非毕业年级**本科生，以二、三年级为主要参与群体；鼓励跨年级、跨专业组队，一般 **3–5人**。
- **2026年度在研项目团队**：根据项目阶段参与中期检查或结题验收；不应把“申报预立项”和“已有项目结题”混为一谈。
- 公告位于**教师通知**栏目、收件人为“各学院”；学生具体申报/答辩时间应向本学院确认。

## 与学生直接相关的规定

1. **先预立项，后评等级**：未参加此次校内预立项的项目，不纳入后续校、省、国家级项目等级遴选。2027年4月预计开展正式立项与等级评定。
2. **参与数量**：每名学生最多同时参加两个“大创计划”项目，但不得同时担任两个项目负责人；国家级项目成员或负责人在项目结题前不能再申报其他项目。选题不得与历年已立项项目重复。
3. **研究与团队**：创新训练通常实施1年，原则上不超过2年；科研训练以教师课题为依托、师生互选。
4. **系统入口**：学校官网 → 登录数字东林 → 搜索“智慧双创系统”，进行申请、中期检查和结题操作。不要在第三方网页输入数字东林密码。
5. **项目与竞赛**：通知要求立项后参加2027年中国国际大学生创新大赛；在研项目结题也有相关参赛要求。
6. **经费与学分**：通知规定科研训练项目为校级、经费由指导教师科研经费支出，标准不低于5000元/项，**并非直接给学生个人的奖金**；通过结题验收的学生团队可获得创新学分奖励。

## 时间、状态与误读防范

- **通知发布日期**：2026-11-11；本条复核日期：2026-11-12。
- **2026-12-27前**：原文要求**各学院**完成相关评审、材料提交等工作，**不能直接等同于学生个人报名截止时间**。学生应尽早询问所在学院具体的校内截止时间、导师选择及答辩安排。
- **2027年4月**：通知对后续省级平台申请及正式立项等采用预计表述；应以届时新通知为准。
- 适用状态：本轮核验时为**尚未到校级材料截止日**；未确认各学院内部报名窗口是否已开放。

## 如何开始（学生可执行）

1. 向本学院创新创业负责老师确认报名窗口、所需表格、评审安排。
2. 找到有资格指导的教师，准备与历年立项不重复、可在毕业前完成的选题；跨专业协作也可考虑。
3. 组建一般3—5人的团队，明确负责人和成员是否已有其他在研项目。
4. 登录数字东林“智慧双创系统”核对具体操作，提交前复核学院通知。
