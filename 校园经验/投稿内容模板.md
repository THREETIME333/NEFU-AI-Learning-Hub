## 内容

### 亲历事实或可核实信息

写下能确认的内容，明确条件、时间和来源。个人经历不要推论为所有学生的普遍情况。

### 个人观点或建议

可支持、质疑或批评学校的政策与服务；与客观事实分开表达。

### 适用边界与可能的变化

说明哪些情形可能不适用，规则或服务是否可能更新。

### 其他合理观点（如存在）

平等记录有依据的不同意见，不虚构反对者或支持者。

### 参考来源

公开 URL、出处和核验日期。无证据时标注“尚未核实”，不能冒充官方通知。

## 管理员审核

- [ ] 内容可公开、没有他人隐私和未经许可的附件
- [ ] 类型与来源分类准确
- [ ] 学生确认公开版本，且了解 GitHub 投稿者账号可见
- [ ] 涉及规则时已核实官方有效版本
- [ ] 不包含未核实的针对特定个人的严重指控
- [ ] 去重、必要时补充不同观点
- [ ] 审核通过后创建 `校园经验/条目/*.md` 并更新 `community_catalog.json`
- [ ] 运行 `python scripts/validate_community.py`，提出 PR
