# 校园经验与学生建议库

此目录等待校内同学贡献真实经历和有依据的信息。**目前未预填任何“学长学姐经验”或“学校规定”**，避免让 AI 把编造的经验当作真实记录。

## 可以交流的内容

- **学长学姐经验**：课程选择、学习方法、实习、考研和校园生活，说明适用学院、年份与个人条件。
- **校园生活提醒**：报到、交通、生活服务、选课和日常注意事项，标明发布日期以及可能变动的因素。
- **校规理解与建议**：附学校公开规则的标题、URL、适用日期，再清楚写明个人看法。批评、赞同及改进建议都可以表达，但不能编造官方规定。
- **学生点子**：教学资源、公共设施、学生协作等改进想法；明确为提议，不冒充学校已实施的政策。

## 收录标准

AI 可以帮助学生润色和匿名化投稿，但是不能替学生虚构亲历、身份或数据。真实个案与一般建议应当分开。个人姓名、学号、联系方式、宿舍房号、未公开的私人对话及可以指认个人的细节不要上传。

每个正式收录的 Markdown 文档须包含：标题、条目类型、主题、适用范围、原始投稿或公开来源说明、发布时间、最近复核时间、可信度/核验状态、争议与适用边界。记录由审核者确认为可公开后，才能进入 `community_catalog.json`。

原始 Issue 属于**待审核材料**，不能被学生 AI 当成准确事实。不同意见可以并存，不因某个意见不受欢迎就判为“事实错误”。涉及失实指控、人身攻击或隐私泄露的内容不得公开。
