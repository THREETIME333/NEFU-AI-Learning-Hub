# NEFU AI Learning Hub · 东北林业大学 AI 学习与校园经验库

> **学生自发的非官方公共项目，与学校没有隶属或背书关系。** 学生通过自己的 AI 查询课程、公开讨论和校园经验；仓库由维护者与授权 AI 整理、校验、提交改进。

## 🚀 学生只需问一句

在**支持 GitHub 文件访问**的 AI 客户端中发送：

> 请读取 https://github.com/THREETIME333/NEFU-AI-Learning-Hub 的 `HUB_INDEX.json` 和 `AI_START_HERE.md`。我想了解【在这里写问题】。请自动定位资料，说明来源与日期，区分学校规则、学生经历与观点；不知道就直说，不要编造。

比如直接问：“数据结构有哪些可以练的题？”“东林宿舍怎么样？”“大家对校园网有什么不同看法？”“今年转专业怎么规定？”

**学生不需要了解目录和 JSON，也不需要操作 Git。** 但普通 DeepSeek 网页聊天不一定有 GitHub 读取工具；需使用实际支持仓库读取的 AI Agent/MCP 客户端。

## 📚 一个入口，四个内容模块

| 你想了解什么 | 进入模块 | 数据性质 |
|---|---|---|
| 课程、真题、题解 | [课程与真题](catalog.json) | 原创教学材料；历年原卷必须有公开授权 |
| **大家讨论什么、不同观点是什么** | [公开学生讨论](DISCUSSIONS_START_HERE.md) · [专题目录](discussion_catalog.json) | 按问题整理公开来源，**不是全校民调** |
| 选课、学籍、学校制度、学长学姐建议 | [校园规则与经验](CAMPUS_START_HERE.md) | 校方公开规则与学生经验严格区分 |
| 最近有哪些公开话题与来源 | [跨平台资料发现](sources/platform-scan/2026-11-04-全平台公开资料巡检.md) | 带日期的历史扫描快照，不是实时信息流 |

所有模块由 [`HUB_INDEX.json`](HUB_INDEX.json) 自动路由。AI 按需阅读具体文档，不应每次扫描整个仓库。

## 🔎 当前已有哪些资料？

- **课程**：数据结构与离散数学复习导航、原创练习、概率论原创讲解、学校公开课程入口，以及概率论 15 套历史考试的**校内资料线索**。
- **公开学生讨论（首批 3 个）**：[宿舍条件](学生讨论/专题/宿舍与住宿条件.md)、[校园网及学习设施](学生讨论/专题/校园网络与学习设施.md)、[食堂与生活体验](学生讨论/专题/食堂与日常生活体验.md)。每个专题都保留来源链接、年代与适用局限，**不能据此断言全校同学普遍认同**。
- **政策与经验**：[2026 年秋学期选课、学籍等官方信息导航](校园经验/条目/2026秋学期官方选课学籍与转专业导航.md)；尚无经学生授权审核的真实学长学姐原创投稿。
- **公开平台**：阳光高考、官方学院新闻、匿名体验问卷、贴吧、抖音、B站等 [扫描来源记录](sources/platform-scan/2026-11-04.json)，保留核验状态。

**现在尚未收录有明确公开转载授权的完整历年原卷。** 非公开课件、教材扫描件和学生隐私不能直接搬运。其他平台帖子也只保留原创归纳和原链接，不能未经授权复制整帖。

## 💬 学习后怎样反哺？

学生只需告诉自己的 AI：“帮我把这条经验或勘误整理后贡献回仓库，不要透露个人信息。” 有权限的 AI 可在学生明确同意公开后创建 Issue / PR；**不是每个 AI 都天然拥有写入权限**。贡献经过来源、隐私、版权、时效和准确性审核，才能进入正式索引。
