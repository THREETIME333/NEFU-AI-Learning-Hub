## 数据处理逻辑

1. **来源发现层**：只保存原链接、标题、来源日期及简短独立描述。
2. **讨论专题层**：把同一主题的不同平台资料聚合，记录关注点、相反意见和适用条件。
3. **官方核验层**：涉及当前规则时通过学校当年的官方文件核对；不能拿帖子作规则。
4. **AI 答复层**：学生一句自然语言发问，AI 从专题引用到来源；不要求学习 GitHub。
5. **贡献回流**：由具备权限的 AI 代写 Issue/PR，经过审核才合并。

**“多来源重复提及”不等于大多数同学认同。** 只有可描述的样本、取样方法和统计数据才有资格讨论比例。
