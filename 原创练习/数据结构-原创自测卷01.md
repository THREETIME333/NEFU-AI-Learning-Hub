## 参考答案与解析

1. **B，5 次**。删除索引 2 后，下标 3–7 共 5 个元素左移。
2. **B，6 次**。插入下标 2 时，原下标 2–7 共 6 个元素右移。
3. **C，C B**。栈后进先出。
4. **B，6 个**。牺牲一个数组位置区分空与满。
5. **B，9**。`p` 保存 `a` 的地址，`*p` 访问并修改 `a`。
6. **B，`([])`**。括号必须按最近未匹配左括号配对。
7. **B，`O(log n)`**。`i` 每次翻倍，直到 `i>√n`；迭代数约为 `log₂√n=(1/2)log₂n`。
8. **C，`O(n)`**。要检查每个输入元素，线性算法可做到时间 `O(n)`。
9. 参考函数：

```cpp
#include <vector>
using namespace std;
int countPositive(const vector<int>& a) {
    int ans = 0;
    for (int x : a) if (x > 0) ++ans;
    return ans;
}
```

10. 参考完整程序：

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x;
    cin >> n;
    cin >> x;
    int best = x;
    for (int i = 1; i < n; ++i) {
        cin >> x;
        if (x > best) best = x;
    }
    cout << best << '\n';
    return 0;
}
```
