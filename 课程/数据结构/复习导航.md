# 数据结构：从零到自测的学习导航

> 类型：`知识整理`。这是一份基于通用数据结构内容的学习路线，**不是东北林业大学官方考试大纲、真题范围或押题清单**。实际考试以任课教师要求为准。

## 学习主线

**线性表 → 栈和队列 → 串与数组 → 树 → 图 → 查找 → 排序**。不同课程的讲授顺序可能不同。

| 专题 | 必须能独立解释 | 常见误区 | 检查方式 |
|---|---|---|---|
| 顺序表 | 插入、删除时的数据移动；边界与长度更新 | 在循环中遗漏 `i >= 0` 或忘记 `length++` | 用空表、表头、表尾位置手工模拟 |
| 链表 | 结点指针变化；插删结点；头结点 | `p` 与 `p->next` 混淆；删结点后悬空指针 | 画每一步指向图 |
| 栈 | LIFO、入栈出栈、括号匹配、表达式求值 | 只看字符串长度判断括号匹配 | 逐字符跟踪栈顶 |
| 队列 | FIFO、顺序/链式、循环队列下标回绕 | 把队空与队满混淆；误用 `free`/`delete` | 测试空队、单元素、队满 |
| 树 | 度、深度、遍历、二叉树 | 误把任意树等同于二叉树 | 手画前/中/后序遍历 |
| 排序 | 稳定性、时间/空间复杂度 | 以“平均很快”推断“最坏也很快” | 设计有序、逆序、重复值用例 |

## 最容易出错的三个示例

**1. 为什么顺序表删除位置 i 的元素要移动元素？**

数组连续存储。若表长为 `n`，按 0 开始下标，删掉 `i` 后，`i+1` 到 `n-1` 的 `n-i-1` 个元素都要向前移一格；新长度为 `n-1`。删除最后一个元素时，移动 0 个。

**2. 循环队列取模为什么重要？**

例如容量为 `m` 的数组，用 `rear=(rear+1)%m` 可在到达末尾后回到下标 0。具体判空判满公式取决于 `front/rear` 的定义和是否牺牲一个存储单元，不能混用不同教材的约定。

**3. 为什么 `i*i <= n` 的循环不总是 `O(√n)`？**

只有当 `i` 逐次线性增加且从固定起点出发时，循环次数才近似 `√n`；如果 `i` 每次翻倍，则轮次约为 `log n`。**循环条件与更新语句必须一起判断。**

## 复习建议

1. 先学数据结构的不变量与指针/下标含义。
2. 给每个操作设计**空、单元素、一般、多元素、边界**测试。
3. 自己写一遍不看答案的实现，并说明时间复杂度。
4. 把错误归类为边界判断、指针关系、内存管理、复杂度四类。
