## 使用方法

- **浏览器/手机**：打开网站首页按课程筛选，点击“复制完整 AI 学习包”，粘贴到 DeepSeek 或 ChatGPT。
- **已连接 GitHub 的 Agent**：给出公开仓库地址，要求读取 `catalog.json` 并筛选 `course=数据结构`，按 `AGENTS.md` 的建议辅导。
- **纯 GitHub 页面**：直接打开[数据结构复习导航](复习导航.md)或[原创自测卷 01](../../原创练习/数据结构-原创自测卷01.md)，把正文和 `LEARN_WITH_AI.md` 复制给 AI。
