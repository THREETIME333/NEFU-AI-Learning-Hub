# 百度贴吧 → 校园 AI 知识库：来源发现和审核流程

本流程服务于学生获取公开讨论中的**经验线索与观点摘要**。目标不是镜像贴吧、复制帖子或建立个人资料库。

## 最重要的限制

- 使用搜索引擎公开结果、允许公开阅读的原帖以及**平台明确允许的接入接口**。在程序实际访问网站前检查最新 robots.txt、服务协议、请求频率限制及使用权限。无法确认是否获准自动抓取时，不执行批量爬虫。
- 不绕过登录、验证码、反爬、403、访问频率限制，不通过代理池分散请求，不爬私密群组或仅登录可见内容。
- 不收集用户名、头像、IP 属地、性别、学号、微信号、联系方式、社交关系，也不长期保存整帖正文与图片；公开输出仅保留**原帖 URL + 简短独立概括 + 主题 + 日期 + 不确定性说明**。
- 贴吧帖子是第三方用户作品，公开可见**不等于获得转载许可**。未经明确授权不要复制全文、截图、楼中楼记录或整理成可替代贴吧的全文数据库；应优先链接原帖。
- 不将贴吧中的指控、传闻、匿名爆料、涉及具体个人的评价直接发布为事实；不凭单帖推断所有学生的共同看法。

## 处理流水线

1. **发现**：根据公开可访问范围，检索“东北林业大学吧”里的选课、转专业、校园生活、社团、实习、考研等话题。优先具备实际原帖 URL 的条目。
2. **候选**：AI 将来源元数据写入 `sources/tieba/candidates.json`，字段包括 URL、原帖年份、检索日期、主题、原创归纳、访问状态；禁止保存原帖全文与个人标识。
3. **核验**：区分经验/观点/问题/官方制度。对于学校规定，查东北林业大学公开官方文件，并记录适用年份。仅有“有人问过”不能当成“有人回答了”。
4. **去重与时效**：过时话题保留为历史线索，不代表当前校况；同一观点来自多帖时不将重复转发伪装成多份独立证据。
5. **贡献提案**：符合条件则由具备权限的 AI 创建 Issue / PR，正文用自己写的简短主题摘要、原帖 URL、核验状态及官方参考资料，待可信任维护者核验。不能直接把待审内容登记为正式学生经验。
6. **公开发布**：只有来源、权利、准确性、隐私和适用时间已确认，才在校园经验区收录审核通过的 Markdown，并更新 `community_catalog.json`。`consent_to_publish` 指对拟发布原创文档的有效授权；不能由“网上可见”推导出原作者授权。
7. **复查与撤回**：遇到原帖删除、学校政策变化、信息纠错，标记过时/不可用，按项目贡献规范复核或撤下。

## AI 对学生如何回答？

若社区目录为空，AI 应说明暂无**已审核**的学生经验；可以另行报告“找到过但还没有核实”的帖子链接，仅当作发现线索，不能混用两种可信度。

### 当前初步发现

已记录一条 2016 年的历史社团讨论链接作为**抓取流程示例**。它年代久远且原帖目前可能有限制，不能用于回答当年的社团名单、群号、收费情况是否仍有效。

## 下一阶段（尚未部署）

只有核实平台允许自动访问和采集范围后，才考虑定时任务或人工批准的低频采集。GitHub Actions 能执行校验，但**仓库中有提示词不会自动在后台运行大模型**。自动采集也不应依赖未经许可的反爬规避服务。
