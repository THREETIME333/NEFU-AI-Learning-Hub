# 课程资料与真题的标准（面向 AI 解析）

## 唯一索引

`catalog.json` 列出**已经实际存在**的材料。禁止通过单独添加索引占位年份制造“已收录真题”的假象。`AI_INDEX.md` 由脚本生成，不手工维护。

支持类型：

- `authorized_past_paper`：经过来源与转载权利核查的**完整**历年试卷。需年份、考试类型与 `verification=permission_checked`、`rights_basis`、`source_evidence`、`reviewer`；仍不能直接称官方认证。
- `student_recollection`：学生概括的考试考点和学习经验，非原卷；不能照搬未授权的原题文本。
- `original_mock`：原创练习与答案，年份必须 `null`，必须显著写明“非历年真题”。
- `study_note`：原创教学笔记；不能把基于某次考试的个人推测写成普遍规定。
- `official_link`：校方公开资源的入口及说明，不绕过登录权限。

## 推荐 Markdown 文档骨架（不要把模板加入 catalog）

```markdown
# 数据结构 · 期末复习卷（示例标题）

- 资料类型：经授权历年卷 / 学生回忆 / 原创模拟（三选一）
- 课程：数据结构
- 年份：确知才填写，其他写“未知”
- 学期：确知才填写
- 来源：公开网址或原始来源的可公开说明
- 公开依据：授权说明或独立原创依据
- 核验状态：已核实 / 待核实
- 标准答案状态：官方公开答案 / 独立推导参考答案 / 待核实

## Q001 · 题目标题
题干……

<details><summary>参考解析</summary>

**答案**：……

**原理**：……

**逐步推导**：……

**易错点**：……

</details>

## Q002 · ...
```

## 稳定标识

- `catalog.json` 中每篇资料 `id` 全局唯一、长期不变。
- 试题内使用 `Q001`、`Q002` 等稳定题号，便于 AI 精确引用和仓库去重。
- 引用格式：`[课程/年份/题号] 文件路径#Q001`，年份不明则注明“未确认”。
- 别把图片截图当作唯一正文；尽可能提供有权公开的文字版本，公式用 Markdown/LaTeX。无障碍文本是 AI 检索的基础。

## 真实性与隐私

本仓库**不负责提供未授权的校内非公开试卷**。关于“历年考点”的学生回忆，只能反映那名学生的个人经验，不可假装学校官方宣布。投稿中含姓名、学号、个人成绩、聊天记录的部分不得自动进入公共仓库。
