# 学生共建：搜索咨询、经验投稿、纠错

学生可直接用自然语言向 AI 投稿，不要求他们学习 git 命令。**只读使用无需 GitHub 账号；公开 Issue/PR 会暴露提交者的 GitHub 身份。**

## 投稿路径

1. 学生说“我想分享选课经验/校园问题/补充资料”。先理解内容、适用学院/课程/年级、发生时间及是事实还是个人观点。
2. 不直接上传聊天全文；制作**简短原创脱敏草稿**，去除姓名、学号、手机号、QQ/微信、私人住址、成绩、聊天截图、涉事者可识别细节、密钥等。
3. 检查公开权利：第三方贴吧/知乎/小红书文章不能直接整篇复制；非公开历年试卷、教材、教师课件、私有笔记不可擅自上传。公开网页也不自动代表允许转载。
4. 向学生展示拟发布的**完整内容及将公开的平台**，得到明确同意后才提交。用户原先仅要求“查一查”“总结”不算同意公开。
5. 有仓库写入/Issue 权限时，按 `COMMUNITY_CONTRIBUTING.md` 与 `AGENTS.md` 建 Issue 或待审 PR；**不要默认直推 main**。回复真实链接及操作结果。
6. 无写入能力时提供草稿和 [投稿入口](https://github.com/THREETIME333/NEFU-AI-Learning-Hub/issues/new/choose)；不说“已发布”。
7. 涉及可能影响奖学金、处分、保研、转专业资格的说法，等待校方有效公告或明确列为未核实的观点。

## 发表前检查

- 是否会把具体学生与班级、宿舍号、辅导员、联系人直接关联起来？
- 是否有他人未经许可的图片、试卷、录音、对话全文或私人内容？
- 是否区分“本人经历”“道听途说”“公开文件”“建议/评价”？
- 是否有原始来源/适用时间？观点是否被描述成了全校共识？
- 学生是否**明确同意公开这版脱敏草稿**？

## 纠错

学生指出错误时，先打开原文件核对，做最小修正并保留来源；如果无法核对，记录待复查而不是偷偷改写事实。未获审稿许可，不应直接把有争议或涉及个人的资料推到公共主分支。
